# Academic submissions

- `final/` — original Deliverables 1–3, with figure exports in `final/exports/`.
- `briefs/` — supplied summative project and presentation PDFs.
- `diagrams/` — editable PlantUML diagram sources and existing renders.
- `planning/` — Jira board export.
- `scripts/` — historical document and diagram generation tools.

Final documents, briefs, diagrams and exports were moved without modifying their contents. All 28 moved files passed SHA-256 comparison immediately after relocation; only script paths were then updated.

Generation scripts write to `generated/`, never over the final submitted documents. Some historical Deliverable 3 source assets were already absent before cleanup; the final document and its exported figures remain available. These scripts are retained for reference and are not claimed to fully reproduce the final submissions.
