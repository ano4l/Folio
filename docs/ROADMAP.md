# Folio roadmap

## Phase 0 — Frontend foundation (current)

- Rebuild the supplied JSX experience in Next.js and TypeScript.
- Validate navigation, upload feedback, document detail, source-grounded Q&A patterns, deadlines, and security screens.
- Scaffold Spring Boot, PostgreSQL, Docker Compose, and Railway deployment shape.

## Phase 1 — Secure pilot

- Eduvos OIDC login and MFA.
- PostgreSQL document metadata and audit tables.
- S3 signed uploads with virus/type/size validation.
- OCR and document processing status.
- Connect the vault and deadlines screens to the API.

## Phase 2 — Trusted intelligence

- Classification and structured extraction evaluation set.
- Chunking, embeddings, authorised retrieval, citations, and answer confidence.
- Human review queue for low-confidence extraction.
- Student feedback on answer helpfulness and citation quality.

## Phase 3 — Pilot operations

- Notifications and deadline reminders.
- Consent-based financial-aid staff workflows.
- POPIA data export and deletion workflows.
- Monitoring, rate limits, backups, incident runbook, and cost controls.

## Phase 4 — Expansion

- Flutter mobile client if research validates demand.
- Additional institutions and configurable document taxonomies.
- Accessibility and multilingual content improvements.
